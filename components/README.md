# components

Reusable React Three Fiber components, grouped by domain:

| Folder | Purpose |
|---|---|
| `atmosphere/` | Sky, haze, fog, scattering |
| `clouds/` | Cloud systems (see also the standalone `/volumetric-clouds` package) |
| `environment/` | Scene rigs, HDRI, biomes |
| `lighting/` | Sun/moon, ambient, time-of-day |
| `ocean/` | Open ocean and shoreline |
| `terrain/` | Heightfields and ground |
| `weather/` | Rain, snow, wind, storms |
| `water/` | Inland water: lakes, rivers, ponds |
| `effects/` | Post-processing, particles, VFX |
