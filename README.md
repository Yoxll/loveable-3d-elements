# loveable-3d-elements

Shared library of 3D assets and components for Lovable island / digital-forest projects.

## Asset taxonomy

```
assets/
├── fauna/            # animal life
│   ├── birds/
│   ├── mammals/
│   ├── reptiles/
│   ├── amphibians/
│   ├── fish/
│   ├── insects/
│   ├── pollinators/
│   └── marine-life/
├── flora/            # plant life
│   ├── trees/
│   ├── shrubs/
│   ├── flowers/
│   ├── grasses/
│   ├── ferns/
│   └── fungi/
├── geology/          # landform and ground
│   ├── rocks/
│   ├── cliffs/
│   ├── caves/
│   ├── sand/
│   └── soil/
├── water/            # water bodies, shaders and surfaces
├── structures/       # buildings and built elements
├── vehicles/         # boats, land and air vehicles
├── textures/         # image maps
├── materials/        # material definitions and presets
├── audio/            # ambient and event sound
└── effects/          # particles, weather and atmospheric FX
```

Each folder has its own README describing what belongs there.

## Packages

- `volumetric-clouds/` — drifting volumetric cloud components (unchanged by the asset taxonomy).
